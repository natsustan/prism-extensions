# Changelog

## 1.0.0

- Connect to Macs discovered automatically on the local network via Bonjour (`_rfb._tcp.`), with instant cached loading and background refresh.
- Support direct connection by typing an IP address, hostname, `user@host:port`, or `vnc://` URL in the search field.
- Pin favorite hosts, track recent connections, configure extra hosts in settings, and open the list directly from Screen Sharing’s row with Tab.
