# Changelog

## 1.0.0

- **Search Bear Notes**: search notes by title, tags, content, or pinyin, filter by Pinned, Todo, Untagged, Locked, or Archived (⌘P), preview Markdown in the detail pane, create a note when nothing matches, and open, copy, archive, or trash notes in Bear.
- **Search Bear Tags**: browse and search active Bear tags with note counts and pinyin, and open them in Bear.
- **New Note from Clipboard**: create a new Bear note from clipboard text.
- Tab on Bear’s own row in root search opens Search Bear Notes.
- Localized in English, Simplified Chinese, and Traditional Chinese.
