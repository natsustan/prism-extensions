# Changelog

## 1.2.0

- In Simplified or Traditional Chinese, sections, actions, messages, and the
  detail pane are in Chinese too. CSS color names and format names stay as
  they are written in code.

## 1.1.0

- When Prism runs in Simplified or Traditional Chinese, it shows this
  extension's name, description, commands, and setting in that language, and
  Chinese words find its commands in search.

## 1.0.0

- Pick Color: pick a color anywhere on screen and copy it in your first format.
- Colors: the colors you picked, with favorites, names, and every format.
- Convert Color: type or paste a color or a CSS color name and copy it in any
  format.
- Formats: choose and order HEX, RGB, HSL, OKLCH, LCH, Display P3, and SwiftUI.
