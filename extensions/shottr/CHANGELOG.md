# Changelog

## 1.0.0

- Added **Shottr Actions**, a searchable list of all 14 Shottr URL-scheme actions that also opens with Tab from Shottr’s own row in root search.
- Added post-capture actions (`Copy`, `Save`, `Edit`, `Pin`, `Show Thumbnail`), delay presets (`3s`, `5s`, `10s`), and **Copy URL** in the ⌘K action panel.
- Added direct commands for **Capture Area**, **Capture Fullscreen**, **Capture Window**, **Capture Scrolling**, and **Capture Text (OCR)** with automatic launcher dismissal before capture.
- Added preferences to control closing Prism before capturing and the default delayed-capture wait time.
