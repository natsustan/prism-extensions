# Shottr

Take screenshots, scrolling captures, and OCR text captures with Shottr from Prism.

- **Shottr Actions** lists every Shottr URL-scheme action — Area, Fullscreen, Window, Scrolling, Scrolling Reverse, Delayed, Repeat, Append, OCR, Load from Clipboard, Load from File, Uploads, Open Shottr, and Shottr Settings. Filter with ⌘P (`Capture` or `Tools`). On any capture row, ⌘K offers post-capture actions (**Capture and…**: Copy, Save, Edit, Pin, Show Thumbnail), **Capture Without Closing Prism**, and **Copy URL** (⌘⇧C); **Capture Delayed** also offers 3s, 5s, and 10s presets under **Delay…**.
- Shottr’s own row in root search offers **Shottr Actions** too: select Shottr and press Tab to browse all actions inside it; Backspace in the empty search returns to Shottr.
- **Capture Area**, **Capture Fullscreen**, **Capture Window**, **Capture Scrolling**, and **Capture Text (OCR)** are also available directly from root search and can be bound to global hotkeys.

## Setup

1. Install [Shottr](https://shottr.cc) 1.8 or newer.
2. Open Shottr **Settings → Advanced** and enable **URL Schema API**.

Requires Shottr 1.8+ with URL Schema API enabled. Declares no extra capabilities.
