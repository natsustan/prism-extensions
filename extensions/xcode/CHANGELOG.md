# Changelog

## 1.0.0

- **Recent Projects**: browse and open recently used Xcode projects, workspaces, Swift packages, and playgrounds from Prism or by pressing Tab on Xcode’s row.
- Filter by project type with ⌘P, reveal in Finder (⌘⇧F), or copy the project or folder path (⌘⇧C / ⌘⇧D).
- Optional **Xcode App Path** setting to open projects with a specific Xcode installation (such as Xcode Beta).
