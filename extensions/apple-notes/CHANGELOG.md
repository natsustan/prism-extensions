# Changelog

## 1.3.0

- A row's second line starts with when the note last changed (the time
  today, then Yesterday, then the date, following the 24-hour and date
  formats in System Settings) and its folder, then the start of its text,
  so every row has two lines. Notes' default folder isn't named.
- A title written over several lines, or with tabs, shows in full on one
  line instead of stopping at the first break.
- The list has headings only when pinned notes are among the results.

## 1.2.0

- In Simplified or Traditional Chinese, sections, actions, the access row,
  and messages are in Chinese too.

## 1.1.0

- When Prism runs in Simplified or Traditional Chinese, it shows this
  extension's name, description, command, and the request for access to the
  Notes folder in that language, and Chinese words find its command in
  search.

## 1.0.0

- Search Notes: search every note by title, content, folder, tags, or
  pinyin, title matches first, and open them in Notes.
- Tab on Notes' own row in root search opens Search Notes.
