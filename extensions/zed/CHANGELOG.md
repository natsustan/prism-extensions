# Changelog

## 1.0.0

- List recently used Zed folders, multi-folder workspaces, files, and remote SSH or container workspaces, sorted newest first, with the current Git branch shown for local repositories.
- Filter between Local and Remote workspaces with ⌘P, and open Recent Projects directly from Zed’s row in root search with Tab.
- Open local and SSH workspaces in Zed, show local items in Finder, copy paths, and optionally target Zed Preview, Nightly, or Dev via **Zed App Path**.
