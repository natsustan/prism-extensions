# Changelog

## 1.0.1

- Declares the Reminders access it uses through Prism, so the Gallery and the install sheet show it.

## 1.0.0

- Added **My Reminders** powered by EventKit to browse, filter (All, Today, Overdue, Scheduled, Completed, and each reminder list), search (including Chinese pinyin), complete, reschedule, reprioritize, move, delete, and open reminders from the launcher or by pressing Tab on Reminders.app.
- Added **Quick Add Reminder** with live natural-language parsing for English and Chinese dates, times, priorities, `#List` targets, `#tags`, and inline `// notes`.
