# Changelog

## 1.0.0

- List Antigravity projects and recently connected remote SSH hosts, sorted by recent conversation activity, with multi-folder badges and the current Git branch shown for local repositories.
- Filter between Local projects and Remote SSH hosts with ⌘P, and open Recent Projects directly from Antigravity’s row in root search with Tab.
- Open Antigravity for local projects, connect directly to remote SSH hosts with `--ssh-host=`, copy the `agy --project` CLI command, reveal project folders in Finder, copy paths, and optionally target Antigravity Insiders or Dev via **Antigravity App Path**.
